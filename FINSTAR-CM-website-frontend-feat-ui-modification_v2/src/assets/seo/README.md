# SEO Assets

This folder contains assets used for SEO and social media previews:

- `og-image.png` - Open Graph image for social media previews (1200x630px recommended)
- `favicon.ico` - Main favicon file
- `apple-touch-icon.png` - Apple touch icon (180x180px)

## Image Requirements

### Open Graph Image (og-image.png)
- Size: 1200x630 pixels
- Format: PNG or JPG
- Used for: Facebook, LinkedIn, WhatsApp, etc.

### Twitter Card Image
- Same as Open Graph image
- Twitter will use the og:image if twitter:image is not specified

### Favicon
- Size: 32x32 pixels (minimum)
- Format: ICO or PNG
- Used for: Browser tabs, bookmarks
